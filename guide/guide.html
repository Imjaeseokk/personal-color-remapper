User guide

Make your first color rule in a few minutes.

Pick a difficult color, choose a clearer replacement, and save it for the site you are using.

01

Create your first rule

  1. Open the extension on the website you want to adjust.
  2. Select Pick color from page, then click an element.
  3. If the element has several colors, choose text, background, border, fill, or stroke.
  4. Choose a Target color and adjust Similarity. A value of 0 changes only an exact match; 15 includes nearby shades.
  5. Check the Preview, then select Add rule & save.

You can also type Source and Target colors directly in the Popup. Unsaved previews are restored when the Popup closes.

02

Choose a likely red and green mix-up

The picker checks CSS and SVG colors used on the current page. It highlights pairs that may look more alike under protan and deutan simulations and shows how often each color appears.

Select a suggestion to use it as the Source. The color after “may resemble” is another color from the same page that could be confused with it.

03

Try an automatic replacement

Auto target · same brightness & saturation looks for a clearer blue, cyan, or purple while keeping the original color's perceived lightness and saturation as close as possible.

Use Preview to check the result against the page around it. You can always adjust the suggested color yourself.

04

Name your rules

New rules start with a name such as rule_1_github.com.

  • Rename gives the rule a name you will recognize later.
  • Default restores the generated name.
  • Generated rule numbers update when you reorder or delete rules.
05

Use a palette on every website

  1. Open Advanced settings and choose the Global profile.
  2. Turn on Profile enabled and save your rules.
  3. Select Allow all websites… and approve site access.

A site's own rules take priority over Global rules. Turning off a site profile also blocks Global rules on that site.

06

Back up and manage palettes

Advanced Settings lets you duplicate and delete site profiles. Export downloads all settings as JSON. Import validates a JSON file before replacing your current settings.

07

Supported content

  • Supported: text, backgrounds, borders, outlines, text decoration, SVG fill, and SVG stroke.
  • Not supported: images, video, Canvas, WebGL, gradients, shadow DOM, and iframe contents.
  • Chrome settings and the Chrome Web Store are protected pages, so extensions cannot change them.
  • If too many colors change, lower Similarity and check the rule order. The first matching rule wins.

01

첫 규칙 만들기

  1. 색을 바꾸려는 웹사이트에서 확장 프로그램을 엽니다.
  2. Pick color from page를 누른 다음 페이지 요소를 선택합니다.
  3. 요소에 색이 여러 개 있으면 text, background, border, fill, stroke 중 하나를 고릅니다.
  4. Target 색을 정하고 Similarity를 조절합니다. 0은 정확히 같은 색만, 15는 비슷한 색까지 포함해요.
  5. Preview로 확인한 다음 Add rule & save를 누릅니다.

Popup에서 Source와 Target 값을 직접 입력해도 됩니다. 저장하지 않은 미리보기는 Popup을 닫으면 원래 상태로 돌아갑니다.

02

헷갈릴 수 있는 적녹 색상 고르기

색상 선택 화면은 현재 페이지에 쓰인 CSS와 SVG 색을 확인합니다. 적색 또는 녹색 계열을 구분하기 어려울 때 비슷해 보일 수 있는 색 조합과 각 색의 사용 횟수를 보여줘요.

추천 항목을 누르면 Source로 들어갑니다. “may resemble” 뒤의 색은 같은 페이지에서 서로 헷갈릴 가능성이 있는 색입니다.

03

자동 대체색 사용하기

Auto target · same brightness & saturation은 원래 색의 밝기와 채도를 최대한 유지하면서 더 잘 구분되는 파랑, 청록, 보라 계열을 찾아줍니다.

Preview로 주변 배경과 함께 확인하세요. 추천받은 색도 원하는 값으로 다시 조절할 수 있습니다.

04

규칙 이름 정하기

새 규칙은 rule_1_github.com 같은 이름으로 시작합니다.

  • Rename으로 나중에 알아보기 쉬운 이름을 붙입니다.
  • Default를 누르면 처음 이름으로 돌아갑니다.
  • 기본 이름의 번호는 규칙을 옮기거나 삭제할 때 자동으로 정리됩니다.
05

모든 사이트에 적용하기

  1. Advanced settings에서 Global 프로필을 선택합니다.
  2. Profile enabled를 켜고 규칙을 저장합니다.
  3. Allow all websites…를 누르고 사이트 접근을 허용합니다.

사이트 전용 규칙이 Global 규칙보다 먼저 적용됩니다. 사이트 프로필을 끄면 그 사이트에서는 Global 규칙도 적용되지 않아요.

06

팔레트 백업하고 관리하기

Advanced Settings에서 사이트별 프로필을 복제하거나 삭제할 수 있습니다. Export는 모든 설정을 JSON으로 내려받고, Import는 파일을 확인한 다음 현재 설정을 교체합니다.

07

지원하는 콘텐츠

  • 지원: 텍스트, 배경, 테두리, outline, text decoration, SVG fill과 stroke.
  • 미지원: 이미지, 영상, Canvas, WebGL, gradient, shadow DOM, iframe 내부.
  • Chrome 설정과 Chrome 웹 스토어는 보호된 페이지라 확장 프로그램이 바꿀 수 없습니다.
  • 너무 많은 색이 바뀌면 Similarity를 낮추고 규칙 순서를 확인하세요. 먼저 일치한 규칙이 적용됩니다.

01

Erstelle deine erste Regel

  1. Öffne die Erweiterung auf der Website, die du anpassen möchtest.
  2. Wähle Pick color from page und klicke ein Element an.
  3. Wenn das Element mehrere Farben hat, wähle Text, Hintergrund, Rahmen, Fill oder Stroke.
  4. Lege die Zielfarbe fest und passe Similarity an. 0 ändert nur exakte Treffer, 15 schließt ähnliche Töne ein.
  5. Prüfe die Vorschau und wähle Add rule & save.

Source und Target lassen sich auch direkt im Popup eingeben. Nicht gespeicherte Vorschauen werden beim Schließen zurückgesetzt.

02

Mögliche Rot-Grün-Verwechslungen wählen

Die Farbauswahl prüft CSS- und SVG-Farben der aktuellen Seite. Sie zeigt Paare, die in Protan- und Deutan-Simulationen ähnlicher wirken können, sowie ihre Häufigkeit.

03

Eine automatische Zielfarbe ausprobieren

Auto target · same brightness & saturation sucht ein klareres Blau, Cyan oder Violett und erhält dabei Helligkeit und Sättigung so weit wie möglich.

04

Regeln benennen

Neue Regeln beginnen mit einem Namen wie rule_1_github.com. Mit Rename vergibst du einen eigenen Namen, mit Default stellst du den generierten Namen wieder her.

05

Eine Palette auf allen Websites verwenden

  1. Wähle in Advanced settings das Global-Profil.
  2. Aktiviere Profile enabled und speichere die Regeln.
  3. Wähle Allow all websites… und erlaube den Website-Zugriff.

Website-Regeln haben Vorrang vor Global-Regeln. Ein deaktiviertes Website-Profil blockiert dort auch Global-Regeln.

06

Paletten sichern und verwalten

In den Advanced Settings kannst du Profile duplizieren oder löschen. Export speichert alle Einstellungen als JSON; Import prüft die Datei vor dem Ersetzen.

07

Unterstützte Inhalte

  • Unterstützt: Text, Hintergründe, Rahmen, Outlines, Textdekoration sowie SVG Fill und Stroke.
  • Nicht unterstützt: Bilder, Videos, Canvas, WebGL, Verläufe, Shadow DOM und iframe-Inhalte.
  • Chrome-Einstellungen und der Chrome Web Store sind geschützte Seiten.
