Personal Color Remapper

내 눈에 맞는 색으로 웹을 다시 읽는 방법

어려운 색을 고르고, 비슷한 색의 범위를 정하고, 구분하기 쉬운 색으로 바꾸세요.

빠른 이동첫 규칙 만들기혼동 색상 추천자동 대체색규칙 이름모든 사이트백업과 관리제한사항
1

첫 규칙 만들기

  1. 바꾸려는 웹사이트에서 Extension 아이콘을 엽니다.
  2. Pick color from page를 누르고 페이지 요소를 클릭합니다.
  3. 요소에 여러 색 속성이 있으면 text, background, border, fill 중 원하는 항목을 고릅니다.
  4. Target과 Similarity를 정합니다. 0은 정확한 색만, 15는 가까운 색까지 포함합니다.
  5. Preview로 확인한 뒤 Add rule & save를 누릅니다.
Popup에서 직접 Source와 Target을 입력할 수도 있습니다. Popup을 닫으면 미저장 미리보기는 원복됩니다.
2

페이지의 적록 혼동 후보 바로 선택

색상 선택 패널은 현재 페이지에서 실제 사용 중인 CSS/SVG 색을 수집합니다. 적색맹·녹색맹 시뮬레이션에서 서로 가까워지는 색상 쌍을 찾아 사용 빈도와 함께 보여줍니다.

제안 항목을 누르면 Source로 들어갑니다. “may resemble” 옆의 색은 해당 색과 혼동될 가능성이 있는 페이지 색입니다. 추천은 진단이 아니며 실제로 불편한 색인지 미리보기로 확인하세요.

3

밝기와 채도를 맞춘 자동 대체색

Auto target · same brightness & saturation은 원본을 OKLCH로 변환한 뒤 밝기(L)와 채도(C)를 유지하면서 파랑·청록·보라 계열 후보 중 적록 색각 시뮬레이션에서 가장 잘 구분되는 색을 선택합니다.

같은 밝기와 채도의 색이 sRGB 화면 범위 밖이면 밝기는 유지하고 채도만 화면에 표시 가능한 수준까지 조금 낮춥니다. 자동 추천 후에도 주변 배경과의 대비를 직접 확인하세요.

4

규칙 이름 관리

새 규칙의 기본 이름은 rule_번호_웹주소입니다. 예: rule_1_github.com.

  • Rename: 이름 입력을 열어 “실패 상태 빨강”처럼 변경합니다.
  • Default: 현재 순서와 사이트 주소를 이용한 기본 이름으로 되돌립니다.
  • 기본 이름 상태의 규칙은 순서를 이동하거나 앞 규칙을 삭제하면 번호가 자동으로 갱신됩니다.
5

모든 사이트에 적용

  1. Advanced settings에서 Global 프로필을 선택합니다.
  2. Profile enabled를 켜고 규칙을 저장합니다.
  3. Allow all websites…를 눌러 사이트 접근을 허용합니다.
도메인 규칙이 Global 규칙보다 먼저 적용됩니다. 특정 사이트 프로필을 끄면 그 사이트에서는 Global 규칙도 적용되지 않습니다.
6

프로필, 백업, 복구

Advanced settings에서 도메인별 프로필을 복제·삭제할 수 있습니다. Export는 모든 저장 설정을 JSON으로 내려받고 Import는 검증 후 기존 설정을 교체합니다. Reset 전에 Export로 백업하는 것을 권장합니다.

7

지원 범위와 문제 해결

  • 지원: 텍스트, 배경, 테두리, outline, text decoration, SVG fill/stroke.
  • 미지원: 이미지, 영상, Canvas, WebGL, gradient, shadow DOM, iframe 내부.
  • Chrome 설정과 Chrome Web Store 같은 보호 페이지에는 적용할 수 없습니다.
  • 저장 후 새 방문에 적용되지 않으면 사이트 권한을 확인하고 열린 탭을 새로고침하세요.
  • 너무 많은 색이 바뀌면 Similarity를 낮추고 규칙 순서를 확인하세요. 먼저 일치한 규칙이 적용됩니다.

모든 처리는 브라우저 안에서 이루어집니다. 서버, 계정, 분석 도구를 사용하지 않습니다.
