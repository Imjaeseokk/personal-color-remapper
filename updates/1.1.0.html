동적 페이지와 생성 콘텐츠를

현대적인 SPA 환경에서 페이지 변화에 대응하는 범위와 성능을 개선했습니다.

새로운 지원 범위

  • ::before와 ::after 생성 콘텐츠의 지원 색상 속성 치환
  • 스타일시트 제거와 :empty 등 텍스트 기반 상태 변화 재평가
  • 페이지 resize, stylesheet load, focus, hover, transition 종료 후 관련 영역 재검사

성능과 복원

직전 처리 시간을 기준으로 batch 크기를 조정해 긴 작업을 줄였습니다. 60초 반복 SPA 검사에서 동적 요소를 계속 추가·제거한 뒤에도 유지 요소 참조가 안정적으로 복원되는 것을 확인했습니다.
