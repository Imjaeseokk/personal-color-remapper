페이지 색상 추천

🙏 🫶 🙇 Personal Color Remapper를 추가해주신 여러분께 진심으로 감사드립니다. 더 편리한 사용을 위한 업데이트 내용입니다.

규칙 이름

  • 개별 규칙에 원하는 이름을 붙일 수 있습니다.
  • 새 규칙은 rule_번호_hostname 형식의 기본 이름을 받습니다.
  • Rename과 Default로 이름을 변경하거나 복원할 수 있습니다.
  • 이전 버전의 규칙도 안전하게 이전되어 기본 이름을 받습니다.

페이지 적록 혼동 색상 분석

현재 페이지의 CSS/SVG 색상을 분석하고 protan/deutan 시뮬레이션에서 서로 가까워지는 색상 쌍을 추천합니다. HEX 값, 사용 횟수, 혼동 가능성이 있는 상대 색상을 표시하며 한 번의 클릭으로 Source를 선택할 수 있습니다.

OKLCH 자동 Target

원본의 지각적 밝기와 채도를 유지하면서 구분하기 쉬운 파랑·청록·보라 계열 색상을 추천합니다. sRGB 범위를 벗어날 때만 채도를 필요한 만큼 조절합니다.

가이드와 품질 검증

  • Popup과 Advanced Settings에서 여는 내장 사용 가이드
  • 새 UI 기준 Chrome Web Store 스크린샷
  • 단위 테스트 13개, Chrome 통합 시나리오 15개
  • 60초 SPA 반복 테스트 전후 유지 요소 참조 20개로 동일
안내

혼동 색상 추천은 접근성 보조 기능이며 의료적 진단이 아닙니다. 실제 페이지에서 Preview로 확인해 주세요.

Named rules

  • Add a custom name to every color rule.
  • New rules use rule_number_hostname by default.
  • Rename a rule or restore its generated name with Default.
  • Older saved rules migrate safely and receive default names.

Red/green confusion suggestions

The page picker analyzes CSS and SVG colors used on the current page and highlights pairs that become more similar under protan and deutan simulations. Suggestions include HEX values, usage frequency, and a possible confusion partner.

Automatic OKLCH Target

Choose a blue, cyan, or purple replacement designed to remain distinguishable while preserving perceptual lightness and chroma whenever the result fits inside sRGB.

Guide and verification

  • Detailed guide linked from Popup and Advanced Settings
  • 13 unit tests and 15 Chrome integration scenarios
  • 60-second SPA stress test with retained element references stable at 20

Color suggestions are accessibility aids, not medical diagnoses. Confirm recommendations with the live preview.

Benannte Regeln

  • Jede Farbregel kann einen eigenen Namen erhalten.
  • Neue Regeln verwenden standardmäßig rule_nummer_hostname.
  • Mit Rename und Default können Namen geändert oder zurückgesetzt werden.
  • Ältere Regeln werden sicher übernommen und erhalten Standardnamen.

Vorschläge für Rot-Grün-Verwechslungen

Die Farbauswahl analysiert CSS- und SVG-Farben der aktuellen Seite und hebt Paare hervor, die in Protan- und Deutan-Simulationen ähnlicher werden.

Automatisches OKLCH-Target

Eine unterscheidbare blaue, cyanfarbene oder violette Ersatzfarbe wird empfohlen. Helligkeit und Farbsättigung bleiben erhalten, wenn das Ergebnis im sRGB-Farbraum darstellbar ist.

Anleitung und Tests

  • Ausführliche Anleitung im Popup und in den Advanced Settings
  • 13 Unit-Tests und 15 Chrome-Integrationsszenarien
  • 60-sekündiger SPA-Belastungstest mit stabilen Elementreferenzen

Farbvorschläge sind eine Bedienungshilfe und keine medizinische Diagnose. Prüfen Sie Empfehlungen mit der Live-Vorschau.
