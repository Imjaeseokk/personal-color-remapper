Version 1.2.0 · 2026-09-23

Named rules and page color suggestions

Thank you for adding Personal Color Remapper! 🙏 🫶 🙇 Here is what we added to make it easier to use.

Give every rule a useful name

  • Add a custom name to any color rule.
  • New rules start with a predictable rule_number_hostname name.
  • Rename a rule whenever you like, or use Default to restore the generated name.
  • Rules saved by older versions are migrated safely.

Find colors that may look alike

The page picker checks the CSS and SVG colors in the page and calls out pairs that become more similar in protan and deutan simulations. It shows each HEX value, how often it appears, and the color it may resemble.

Get a practical target color

The new OKLCH suggestion keeps perceived lightness and saturation as close as it can while moving the color toward a more distinguishable blue, cyan, or purple.

Guide and verification

  • A detailed guide is available from both the Popup and Advanced Options.
  • 13 unit tests and 15 Chrome integration scenarios pass.
  • A 60-second SPA stress test finished with all 20 retained element references stable.

Color suggestions are an accessibility aid, not a medical diagnosis. Use the live preview to choose what feels clearest to you.

규칙마다 알아보기 쉬운 이름을 붙일 수 있어요

  • 각 색상 규칙에 원하는 이름을 붙일 수 있습니다.
  • 새 규칙은 rule_번호_hostname 형식으로 시작합니다.
  • 언제든 Rename으로 바꾸고, Default로 처음 이름을 되돌릴 수 있어요.
  • 이전 버전에 저장한 규칙도 안전하게 옮겨집니다.

헷갈릴 수 있는 색을 페이지에서 찾아드려요

페이지에 쓰인 CSS와 SVG 색상을 살펴보고, 빨강과 초록을 구분하기 어려울 때 서로 비슷하게 보일 수 있는 색 조합을 보여줍니다. HEX 값과 사용 횟수, 헷갈릴 수 있는 상대 색도 함께 확인할 수 있어요.

보기 편한 대체색을 추천해요

OKLCH를 이용해 원래 색의 밝기와 채도를 최대한 유지하면서 파랑, 청록, 보라 계열의 구분하기 쉬운 색을 제안합니다.

가이드와 테스트

  • Popup과 Advanced Options에서 상세 사용 가이드를 열 수 있습니다.
  • 단위 테스트 13개와 Chrome 통합 시나리오 15개를 통과했습니다.
  • 60초 SPA 반복 테스트 후에도 유지 요소 참조 20개가 그대로였습니다.

색상 추천은 접근성을 돕는 기능입니다. 실제 페이지의 미리보기를 보며 나에게 가장 편한 색을 골라주세요.

Gib jeder Regel einen verständlichen Namen

  • Jede Farbregel kann einen eigenen Namen erhalten.
  • Neue Regeln beginnen mit rule_nummer_hostname.
  • Mit Rename änderst du den Namen, mit Default stellst du ihn wieder her.
  • Ältere Regeln werden sicher übernommen.

Finde Farben, die ähnlich wirken können

Die Farbauswahl prüft die CSS- und SVG-Farben der Seite und zeigt Paare, die in Protan- und Deutan-Simulationen ähnlicher werden. Angezeigt werden HEX-Wert, Häufigkeit und die möglicherweise ähnliche Farbe.

Erhalte eine praktische Zielfarbe

Der OKLCH-Vorschlag erhält Helligkeit und Sättigung so weit wie möglich und schlägt eine besser unterscheidbare blaue, cyanfarbene oder violette Farbe vor.

Anleitung und Tests

  • Eine ausführliche Anleitung ist im Popup und in den Advanced Options verlinkt.
  • 13 Unit-Tests und 15 Chrome-Integrationsszenarien sind erfolgreich.
  • Im 60-Sekunden-SPA-Test blieben alle 20 Elementreferenzen stabil.

Farbvorschläge sind eine Bedienungshilfe und keine medizinische Diagnose. Wähle mit der Live-Vorschau die Farbe, die für dich am klarsten ist.
