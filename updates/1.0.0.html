내가 선택하는
웹 색상 접근성

고정된 전체 페이지 필터 대신 사용자가 직접 Source, Target과 유사 범위를 정하는 첫 버전입니다.

첫 버전의 주요 기능

  • OKLab 지각 거리 기반 Similarity
  • 텍스트, 배경, 테두리, outline, text decoration, SVG fill/stroke
  • 원본 alpha 유지와 연쇄 변환 방지
  • 사이트별 프로필과 Global 팔레트
  • Popup 실시간 Preview와 정확한 Cancel 복원
  • DOM Picker와 지원 환경의 Screen EyeDropper
  • MutationObserver 기반 동적 DOM 대응
  • JSON Import와 Export

Privacy by design

외부 서버, 계정, analytics 없이 설정을 Chrome 로컬 저장소에만 보관하도록 설계했습니다.
