Personal Color Remapper
Privacy Notice

Effective September 23, 2026 · Version 1.2.0

Local processing

The extension reads webpage DOM and computed CSS colors to replace colors according to rules you select. This processing takes place in your browser. The screen eyedropper, when used, returns a selected color locally. We do not receive page content, selected pixels, browsing history or palettes.

Settings stored on your device

Chrome local extension storage holds source/target HEX colors, similarity thresholds, rule IDs, profile names, hostnames and enable switches. No account is required. The extension has no backend, analytics, advertising, telemetry or cloud synchronization.

Permissions

Temporary current-tab access is used when you invoke the extension. Persistent access is requested for sites you choose, so saved rules can apply on later visits. You can optionally grant access to all regular HTTP/HTTPS websites. Browser-protected pages cannot be remapped.

Sharing and export

The extension does not transmit or sell your data. Export creates a JSON file at your request; you control any subsequent sharing of that file. A profile export can contain the hostnames you configured.

Control and removal

You can edit or delete profiles, reset stored settings, revoke website access in Chrome, or uninstall the extension. Reset does not revoke Chrome permissions; those can be managed separately. Reload already-open pages after revoking site access to remove existing content scripts.

Contact and updates

For support, use the publisher contact provided on the extension's Chrome Web Store listing. Any future change introducing external data processing would require a new privacy notice and an explicit consent design.
