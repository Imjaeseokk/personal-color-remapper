# Store listing draft

## Name
Personal Color Remapper

## Short description
Choose difficult colors and remap similar colors with personal, per-site palettes. Local and private.

## Detailed description (English UI)

Make webpage colors easier to distinguish with your own rules.

Choose a source color, pick a replacement, and adjust a similarity slider. Personal Color Remapper uses OKLab color distance to match nearby colors and previews your changes on the current page.

Features:
- Enter source and target HEX colors or select them visually.
- Pick original CSS colors directly from a page. A screen eyedropper is also available when supported.
- Adjust similarity and preview before saving.
- Save different palettes for different hostnames.
- Use global rules with deterministic site-rule overrides.
- Turn the extension or an individual site on and off.
- Manage, duplicate, import and export profiles locally.
- Remap text, backgrounds, borders, outlines, text decorations, SVG fill/stroke, and generated ::before/::after colors.
- Keep original transparency and restore original page styles when disabled.

Privacy:
No account, server, analytics or cloud service. Settings stay in Chrome local storage. The extension does not transmit page content, browsing history, palettes or selected colors to the developer. Site access is requested when you choose to save or pick colors on a site; all-site access is optional.

Scope:
This is a CSS color remapper, not an image/video correction filter. Canvas, WebGL, images, video, gradients, Shadow DOM and iframe contents are not remapped. Inline !important colors and animated styles may override the extension. Chrome-protected pages cannot be modified.

Start with a narrow similarity range and choose targets that preserve readable contrast. No knowledge of color-vision deficiency types is required.
